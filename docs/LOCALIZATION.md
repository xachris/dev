# 中文优先与本地化规范

## 目标

本项目的核心用户和主要使用场景位于中国，因此产品默认以简体中文作为业务语言，同时保留英文代码规范，兼顾学校使用体验和技术维护效率。

## 总原则

**中文是产品语言，英文是代码语言。**

## 用户可见内容

以下内容默认使用简体中文：

- 学生端页面
- 家长端页面
- 教师端页面
- 班主任审核页面
- 学术管理后台
- 系统管理后台的业务说明
- 表单标签
- 状态提示
- 错误提示
- 通知邮件正文
- 使用帮助
- 学校业务文档

必要时可以增加英文副标题或未来提供中英文切换，但 V0.1 不以双语系统作为目标。

## 代码与技术对象

以下内容默认使用英文：

- Python 包名与模块名
- Python 类名与函数名
- 数据库表名和字段名
- API 路径和 JSON 字段
- 枚举值
- Git 分支名
- 技术配置项

示例：

```text
界面显示：仅家长可见
代码枚举：GUARDIAN_ONLY

界面显示：待发布
代码枚举：READY_TO_PUBLISH
```

## 默认环境

- Locale：`zh-CN`
- Django language：`zh-hans`
- Timezone：`Asia/Shanghai`
- 日期显示：优先 `YYYY-MM-DD`
- 时间显示：24 小时制

## 文案原则

学校产品文案应：

1. 使用中国学校工作人员和家长自然理解的表达。
2. 避免不必要的互联网黑话和技术术语。
3. 重要操作使用明确动词，例如“提交”“退回修改”“批准”“发布”。
4. 对学生、家长、教师明确区分“可见”和“不可见”。
5. 安全和隐私提示不使用模糊表述。
6. 正式学校通知保持专业、简洁、可追溯。

## 后续国际化

如果未来集团出现海外校区或确有双语需求，再通过 Django i18n 等机制增加 `en` 等语言包。V0.1 不为了未来可能发生的国际化需求牺牲当前中国用户的使用效率。
